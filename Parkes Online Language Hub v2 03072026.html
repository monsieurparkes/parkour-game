How to Use This Hub

This hub works in most modern browsers, but text-to-speech is optimised for use in Microsoft Edge. If a word isn't being read aloud, try switching to Edge before assuming something's broken — voice availability varies a lot by browser and device.

Parkour: type or paste a comma-separated vocabulary list, then explore the world to find each word's card. Great for reviewing a set of words the whole class has already met.

Picture Parkour: upload images named after their target word (e.g. "un croissant.png") instead of typing text — ideal for younger learners or picture-based vocabulary, and works well as an independent task once a teacher has prepared a set of images.

Parkour Kart: race around a track and drive over the card showing the correct word among several on offer — a faster-paced, more physical spin on the same vocabulary-matching idea.

Potato Parkour: a ready-made vocabulary hunt around a house, with no setup needed — just pick a player and go. Good for a quick warm-up or filler activity.

Go Go Bobot!: a video-based verb-matching game starring Bobot the robot koala. Choose between Statements (pick the sentence matching what Bobot is doing), Commands (pick the video matching a written command), or Questions (watch and answer yes or no) — great for practising verbs and comprehension together.

Whiteboard: a digital canvas for classroom display — add and freely drag/resize/rotate text boxes, images, and a set of built-in tools (a noise-level traffic light, countdown timer, clock, and translated date) via the tools menu. Text automatically colour-codes using the same grapheme rules as the rest of the hub, and everything you set up is saved automatically and restored next time you open it.

Colour Coder: paste any text to colour-code target graphemes instantly, then copy the formatted result into another document.

Custom graphemes: use square brackets around any letters you want excluded from colour-coding rules — useful for exceptions within an otherwise-matching word.

Assessment: add a student's name before starting Parkour, Picture Parkour, or Go Go Bobot!, and a results screen with accuracy, timing, and mistake data will appear once the activity is complete — good for a screenshot to submit as evidence of practice.

⚙️ Silent Interpreter Settings

Connect each student's own device, choose the language they'll hear, and set its own volume - or, if a student only has an iPad with nothing to pair, tick "play on this device's own speakers" instead. English is available as a target language too, for whenever broadcasting an English reading is specifically what's needed.

🎤 Browsers hide device names until you allow this once - it only needs a moment's microphone access to reveal the list, nothing is recorded or kept.

How this works

Cycles through the class in a random order, one student at a time - nothing on screen ever shows a score.

Once a session has started, everything is keyboard-only: ← → moves to the next student, ↑ ↓ quietly awards or removes a point for whoever's showing. No clicking required, so students can't tell you're doing it.
