How to Use This Hub

This hub works in most modern browsers, but text-to-speech is optimised for use in Microsoft Edge. If a word isn't being read aloud, try switching to Edge before assuming something's broken — voice availability varies a lot by browser and device.

Parkour: type or paste a comma-separated vocabulary list, then explore the world to find each word's card. Great for reviewing a set of words the whole class has already met.

Picture Parkour: upload images named after their target word (e.g. "un croissant.png") instead of typing text — ideal for younger learners or picture-based vocabulary, and works well as an independent task once a teacher has prepared a set of images.

Colour Coder: paste any text to colour-code target graphemes instantly, then copy the formatted result into another document.

Custom graphemes: use square brackets around any letters you want excluded from colour-coding rules — useful for exceptions within an otherwise-matching word.

Assessment: add a student's name before starting Parkour or Picture Parkour, and a results screen with accuracy, timing, and mistake data will appear once every word is found — good for a screenshot to submit as evidence of practice.

Game Controls

  • ⬆️ Arrow Up / W / Space — jump (press again mid-air to double jump)
  • ⬇️ Arrow Down / S — crawl under low gaps
  • Shift — hold to run
  • Ctrl + Down — drop through a floating platform
  • ⬆️ Up at a shop door — go inside
  • ⬇️ Down (inside a shop) — go back outside
